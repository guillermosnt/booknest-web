# 📚 BookNest

BookNest es una página web para una librería ficticia, desarrollada desde cero como proyecto personal para practicar y mejorar mis conocimientos de desarrollo web frontend.

El proyecto está enfocado principalmente en crear una interfaz moderna, sencilla y responsive utilizando tecnologías web fundamentales, sin utilizar frameworks.

## 🚀 Tecnologías

* HTML5
* CSS3
* JavaScript

## 🎯 Objetivos del proyecto

Con este proyecto busco mejorar mis conocimientos en:

* Estructuración de páginas mediante HTML5.
* Maquetación y diseño con CSS3.
* Diseño responsive para diferentes tamaños de pantalla.
* Creación de interfaces modernas y cuidadas.
* Uso de JavaScript para añadir interactividad.
* Organización de un proyecto frontend.
* Uso de Git y GitHub para controlar y publicar el proyecto.

## ✨ Características

El proyecto contará con diferentes secciones:

* 🏠 Página principal.
* 📚 Catálogo de libros.
* 🔎 Búsqueda de libros.
* 🏷️ Categorías.
* ❤️ Sistema de favoritos.
* 🛒 Carrito de compra básico.
* 📱 Diseño responsive.
* ✨ Animaciones y efectos visuales mediante CSS y JavaScript.

## 📌 Estado del proyecto

🚧 **En desarrollo**

El proyecto se está desarrollando progresivamente, comenzando por la estructura y el diseño de la página y añadiendo funcionalidades de JavaScript posteriormente.
